Security Vulnerabilities in this Interface

  • Missing CSRF Protection: @csrf_exempt allows cross-site request forgery
  • No Authorization Check: Any logged-in user can assign technicians (should be admin-only)
  • SQL Injection Risk: Device filtering could be exploited with malicious input
  • Information Disclosure: Exposes all maintenance logs without access control
  • LOTO Bypass: No validation before allowing technician assignments to locked-out devices
